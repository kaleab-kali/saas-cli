# E2E Test Plan

Use this as a starter checklist for the generated app.

1. Platform admin can sign in and view organizations, plans, jobs, billing, and audit logs.
2. A user can sign up, create an organization, and access the tenant workspace.
3. Tenant roles enforce expected permissions for settings, API keys, billing, reports, and notifications.
4. Billing flows create invoices and record payments in smallest currency units.
5. Notification preferences, templates, and bulk messages work without cross-tenant leakage.
6. Saved reports can be created, executed, exported, and scheduled.
