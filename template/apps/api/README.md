# {{projectName}} API

NestJS API for the generated SaaS scaffold.

## Commands

```bash
pnpm --filter api dev
pnpm --filter api build
pnpm --filter api start:prod
pnpm --filter api test
pnpm --filter api test:property
pnpm --filter api test:mutation
```

## Runtime

Copy or edit `apps/api/.env` for local development. Production examples live in `.env.production.example`.

The compiled API entrypoint is `dist/src/main.js`.
